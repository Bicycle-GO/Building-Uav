# URBAN SCAN — Building-Uav

대학생 공동 연구 프로젝트의 킥오프 회의를 위한 한국어 웹페이지 초안입니다.

## 실행

`index.html`을 브라우저에서 열거나, Node.js로 `node preview.js`를 실행한 후 http://127.0.0.1:4173 에 접속합니다. 별도 패키지 설치는 필요하지 않습니다.

## 구성

독립된 주소로 접속할 수 있는 5개 페이지로 구성됩니다. 모든 페이지에서 공통 메뉴와 이전·다음 링크로 이동할 수 있습니다.

| 페이지 | 파일 | 내용 |
| --- | --- | --- |
| 홈 | `index.html` | 프로젝트 요약과 각 페이지 진입 카드 |
| 프로젝트 소개 | `project.html` | 항공촬영부터 사람의 검토까지의 과정 |
| 분석 데모 | `analysis.html` | 가상 건축물의 이전·현재 시점 비교 |
| 개발 계획 | `roadmap.html` | 8주 일정 및 MVP 범위 |
| 회의 공간 | `meeting.html` | 안건, 메모, 역할 분담 |

- 프로젝트 목표와 항공촬영 → 데이터 정리 → AI 변화 탐지 → 검토 흐름
- 이전·현재 시점 전환이 가능한 가상 분석 화면
- 8주 MVP 개발 제안 일정과 팀별 역할
- 60분 회의 안건 체크리스트
- 브라우저 로컬 저장 및 TXT 내려받기를 지원하는 회의 메모

분석 도형은 설명용 가상 데이터이며 실제 항공영상, 지도, AI 모델 또는 행정자료에 연결되어 있지 않습니다. AI는 변화 후보를 제시하고 최종 판단은 자료 대조와 사람의 검토를 거치도록 기획했습니다. 일정과 역할은 회의에서 조정할 초안입니다.

회의 메모와 체크 상태는 해당 브라우저에만 저장되며 공동 편집이나 서버 저장은 지원하지 않습니다. 저장 공간이 차단된 환경에서는 메모를 내려받아 보관할 수 있습니다. 글꼴은 Google Fonts에서 불러오며 연결이 없으면 시스템 글꼴을 사용합니다.
