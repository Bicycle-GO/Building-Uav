# BUILDINGSCAN — Building-Uav

AI·GIS·GNSS 기반 농지 건축물 점유 후보 탐지와 현황–기록 불일치 진단을 위한 연구·회의자료 사이트입니다.

## 실행

Node.js에서 `node preview.js`를 실행하고 http://127.0.0.1:4173 에 접속합니다. 정적 파일 호스팅 또는 `index.html` 직접 열기도 가능합니다. 외부 패키지 설치가 필요 없습니다.

## 페이지

- `project.html`: 프로젝트 소개 및 7개 주제별 상세 페이지 안내
- `project-purpose.html`: 연구 방향과 서비스 원칙
- `project-strategy.html`: 미션·비전, 5대 전략/15개 과제
- `project-data.html`: 4종 데이터 역할
- `project-pipeline.html`: 분석 과정과 점유 지표
- `project-diagnosis.html`: 불일치 진단과 확인행동
- `project-questions.html`: 연구질문, 비교방법, 평가지표
- `project-sources.html`: 학습자료 및 참고 원문 링크
- `roadmap.html`: 14주/5개 완료 관문, MVP 범위, 시스템 구성, 평가설계, 역할·장비, 첫 주 실행, 최종 산출물
- `meeting.html`: 날짜별 회의자료와 링크·검토 의견 복사를 제공하는 소통 공간. 기존 10장 순서 보기·확대·원본/ZIP 다운로드 유지
- `analysis.html`: AI 탐지 → GIS 계산 → GNSS 검증 → 조사서 연결 모션 인포그래픽. 재생·일시정지·단계 선택·이전/현재 시점 전환
- `report.html`: 첨부 양식(건물 907) 기반 A4 조사서. 위치도 이미지와 현장 입력을 포함한 1페이지 인쇄·PDF 저장
- 홈: 분석 흐름 모션, 1109 회의공간 바로가기, 실제 분석 플랫폼 연결

## 1109 회의공간

- 고정 링크: `meeting.html#1109`
- `meeting-materials/1109/`에 제공된 PDF와 HWPX 원본을 그대로 보관합니다.
- PDF 브라우저 열기·선택형 내부 미리보기·원본 다운로드, HWPX 다운로드를 지원합니다.
- 자료 링크와 검토 의견을 복사해 사용 중인 메신저로 전달합니다. 실시간 댓글·공동 저장 기능은 제공하지 않습니다.
- 실제 분석 플랫폼: https://gis-decision-platform.vercel.app/ (별도 서비스, 새 창으로 연결)
- Building-Uav 배포 주소: https://building-uav.vercel.app/

## 화면과 인쇄

`theme.css`는 공통 화면 디자인, `home-motion.*`와 `analysis-motion.*`는 모션을 담당합니다. 사용자의 동작 줄이기 설정을 존중하고 재생을 직접 제어할 수 있습니다.

조사서는 인쇄 전 이미지·폰트 로딩을 기다리고 현장 입력을 출력용 텍스트와 동기화합니다. A4 세로 1페이지에 기본정보·위치도·필지 중첩·공부/인허가·현장 확인을 표시합니다. 분석 데모 A-01과 첨부 양식 건물 907은 서로 다른 예시입니다.

## 회의자료

`E:\캡스톤\불법건축물 탐지\(이미지)회의자료`의 `1.png`~~`10.png`를 `meeting-materials/01.png`~~`10.png`로 원본 그대로 복사했습니다. 축소 JPEG는 목록 성능을 위한 것이며 다운로드는 PNG 원본입니다. `manifest.json`에는 원본 이름, 크기, 해상도, SHA-256을 저장합니다. ZIP 안에서는 원본 파일명을 유지합니다.

- 폴더 바로가기: `meeting.html#materials`
- 개별 이미지: `meeting.html#materials/1`~`meeting.html#materials/10`
- 키보드: ←/→, Home/End, Esc. 대화상자 포커스 이동·복귀 지원
- 이전 회의 메모 저장키 `urban-scan-meeting-v1`는 회의 페이지 방문 시 해당 브라우저에서 삭제됩니다. 다른 저장키에는 접근하지 않습니다.

## 범위

이 사이트는 연구·개발계획과 회의자료를 제공하는 정적 사이트입니다. 실제 AI 추론, 행정자료 연계, 공간 DB, 공동 편집·서버 저장은 개발계획의 구현 대상입니다. 분석 데모와 회의자료의 수치는 설명용 예시 또는 목표이며 실험성과가 아닙니다. 오차모의실험 구간은 검증 전 통계적 신뢰구간이나 실제 점유확률로 단정하지 않습니다.

연구 내용은 대화 「건축물 농지점유 플랫폼 연구정리」의 기존 탐지·정량화 계획과 최신 불일치 원인·확인행동 지원 방향을 통합했습니다.
