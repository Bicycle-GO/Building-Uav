14주, 연구와 구현을
하나의 결과로 연결합니다.

범위·담당·산출물·검증 기준을 함께 정한 실행계획안입니다. 데이터 확보 여건과 학사 일정에 맞춰 조정합니다.

개발 범위14주 일정플랫폼 구조실험·검증역할·장비첫 주 실행최종 산출물
01 / MVP SCOPE

작은 지역에서 전체 과정을 완성합니다.

01

필수 · MUST

시범지역 1곳, 데이터 명세·정답 기준, AI 모델 1종, 건축물 폴리곤, 필지별 Aocc·POR·BIR, 근거 카드, 검토상태, 독립 정확도 평가.

02

우선 · SHOULD

대표 사례 약 20개로 불일치 원인과 확인행동을 시연합니다. GNSS·측량자료 검증, 검토이력, 결과표 내보내기를 연결합니다.

03

확장 · STRETCH

두 번째 모델 비교, Monte-Carlo 불확실성, 과거·현재 변화이력, 추가 지역 일반화 평가. 필수 기능이 통과한 뒤 진행합니다.

대표 사례 20개는 첫 시연 규모의 제안값이며 통계적 성능평가 표본수와 다릅니다. 평가 표본수·목표치는 2주차에 자료 여건과 예비실험을 바탕으로 확정합니다. 전국 서비스, 실시간 드론 관제, 자동 법적 판단은 1차 개발 범위에 포함하지 않습니다.
02 / 14-WEEK ROADMAP

5개 완료 관문으로 관리하는 14주

시작일이 정해지면 주차를 실제 날짜로 바꿉니다. 데이터·정답·검증 근거가 부족한 단계에서는 범위를 줄이고 미확정 항목을 기록합니다.

기간 · 완료 관문 실행할 일 산출물 · 통과 기준
1~2주 · G1 문제·자료 확정 문제와 사용자 정의, 시범지역 후보 검토, 데이터 접근·이용조건 확인, 지붕/지상 외곽 정의, 연구질문·지표 고정 요구사항 1쪽, 자료목록, 범위·평가계획. 필수 영상·필지의 확보 경로와 검증 대안을 확인
3~4주 · G2 데이터 준비 좌표계·시점 통일, 타일링·라벨링, 혼동 사례 수집, 지역별 학습/검증/시험 분리, 약 20개 사례 카드 초안 데이터 명세·라벨 지침·분할 목록. 라벨 상호검수와 중복·인접 누수 점검 통과
5~7주 · G3 AI 기준모델 5주 기준모델, 6주 오류 분석, 7주 재현 가능한 추론. 학습 조건·시드·모델 버전 저장 모델 1종, 건물 마스크·폴리곤, F1·IoU와 오탐·미탐 보고. 고정 검증셋에서 기준 충족 여부 검토
8~11주 · G4 공간·현장 검증 8주 폴리곤 정리, 9주 중첩·지표 계산, 10주 기록 연결·원인 규칙, 11주 GNSS 및 독립 표본 검증 필지별 결과표·현장기록·오차표. 수작업 교차검산, 위치·면적 오차 및 자료 미확보 상태 확인
12~14주 · G5 통합·발표 12주 Web GIS·사례 카드 연결, 13주 A/B/C 비교·사용자 점검, 14주 고정 시험셋 평가·보고서·시연 재현 가능한 MVP, 실험결과·한계·후속과제. 입력→분석→근거 확인→검토 저장→결과 출력 전체 시연
03 / SYSTEM DESIGN

분석 결과와 검토 근거가 연결되는 구조

  1. 수집·전처리영상 · 필지 · 기록
  2. AI 추론건물 마스크·영역
  3. 공간 DB필지·객체 연결
  4. 분석·규칙면적 · 원인 · 행동
  5. API·웹지도레이어 · 사례 카드
  6. 검토·피드백현장 · 이력 · 출력
모듈 구현안 저장할 핵심 정보
데이터·AI Python, QGIS, PyTorch 계열 모델. 모델 선택은 데이터·라이선스·장비 확인 후 확정 영상 ID·촬영일·GSD·CRS, 라벨 정의, 공간분할 ID, 학습설정·모델 버전
GIS·저장 GeoPandas/Shapely 등으로 시범 분석, PostgreSQL/PostGIS로 결과 통합 필지 ID, 건물 ID, 원본·분석용 도형, 중첩 도형, Aocc·POR·BIR, 출처 버전
근거·확인행동 설명 가능한 규칙 10~20개 내외를 멘토와 설계. 적용 조건·보류 조건 함께 작성 사례 ID, 불일치 유형, 미확인 정보, 문서·사진 링크, 적용 규칙과 다음 확인행동
웹·검토 지도 라이브러리와 API 연결. 필지 검색·레이어 전환·사례 상세·검토 저장 검토자, 시각, 수행행동, 소요시간, 상태변경 사유, 최종 확인 근거
현재 이 웹사이트는 연구·회의자료를 공유하는 정적 안내 사이트입니다. 실제 항공영상 AI, 공간 DB, 행정자료 조회와 다중 사용자 저장은 위 일정에 따라 구현할 개발 대상입니다.
필지 카드의 필수 필드와 상태

필드: 필지·건물 ID, 영상 촬영일, 자료 갱신일, 경계 기준, 중첩면적, POR/BIR, 위치오차, 원인 가설, 확보·미확보 근거, 권고행동, 담당자, 검토이력.

검토상태: 후보 생성 → 자료 확인 → 추가 확인 필요 / 판단 보류 → 현장 확인 → 검토 완료. 완료는 검토 절차의 완료를 의미하며 적법성의 자동 판정을 뜻하지 않습니다. 상태마다 근거·변경자·시각을 기록합니다.

04 / VALIDATION

탐지 정확도와 업무효율을 함께 검증합니다.

평가영역 방법 보고할 지표
건축물 탐지 시험지역 고정, 객체유형별 성능과 오류 사례 분류 Precision·Recall·F1·IoU, 표본수, 혼동행렬
필지 점유 정량화 같은 경계 기준의 독립 참조자료로 교차검산. 중첩이 없는 표본도 포함 위치 RMSE, 면적 MAE(㎡), 상대오차, 필지 후보 Precision·Recall
공간불확실성 · 선택 GNSS 오차 추정용 자료와 검증용 자료 분리, 위치·임계값·오차모형 민감도 95% 모의구간 포함률·폭, Pocc의 검증·보정, 경계 인접/소형필지별 차이
진단·확인행동 A 지도·면적 / B 원인진단 추가 / C 근거·행동추천 추가. 동일 사례, 순서 효과 통제 추천 적합률, 사례당 시간, 불필요한 방문, 판단 변경률, 검토자 간 일치도
우선순위·재현성 같은 조사 예산 K로 비교하고 비후보 표본으로 누락 조사. 데이터·모델 버전 고정 Precision@K·Recall@K, 비후보 누락률, 재실행 성공 여부
정확도 90% 등 결과 수치를 미리 성과로 표시하지 않습니다. 기준모델·표본·목표값을 평가 전에 정하고 실제 결과를 기록합니다. 참조면적이 0에 가까우면 상대오차만 사용하지 않고 절대오차도 보고합니다.
01

GNSS 자료가 부족할 때

독립 수작업 판독으로 영상 영역을 검증하고, 측량검증 미수행을 명시합니다. GNSS로 보정한 결과라는 주장은 보류합니다.

02

행정자료를 못 받았을 때

공간자료 간 불일치와 검증행동 설계까지 수행합니다. 가상 기록은 시연용으로 표시하고 실제 업무성과와 분리합니다.

03

기간·장비가 부족할 때

모델 1종과 시범지역 1곳을 우선 완성합니다. 추가 모델, 시계열, 확률모형을 후속 연구로 옮깁니다.

05 / TEAM & TOOLS

4인 팀의 역할과 LX·지도교수의 지원

역할 책임 함께 검토할 일
학생 A · 데이터/GIS 자료 확보, CRS·시점 정리, 필지 중첩, 면적 검산 학생 B와 라벨 기준·건물 폴리곤 점검
학생 B · AI 기준모델, 학습/시험 분리, 추론, 오탐·미탐 분석 학생 A와 데이터 품질, 학생 D와 오류 사례 확인
학생 C · DB/API 객체·사례·근거 연결, 규칙 처리, 검토이력·출력 학생 D와 API 명세와 통합 흐름 검증
학생 D · 웹/검증 웹지도, 비교·사례 카드, 사용자 실험·결과 정리 학생 C와 입력부터 검토 저장까지 공동 점검
LX 멘토 · 지도교수 제공 가능한 자료·장비 협의, 측량 의미·확인행동 자문, 연구설계 지도 정답 기준, 독립 평가, 각 단계 통과 여부 공동 검토

장비 확보 순서

보유 PC와 공용 저장장치로 전처리부터 시작합니다. AI는 사용 가능한 GPU 환경에서 작은 예비실험으로 메모리·시간을 확인합니다. 현장 검증은 LX와 RTK-GNSS 지원 가능 범위를 협의하고, 드론은 최신 영상이 꼭 필요한 경우에 추가합니다.

주간 운영 방식

주 1회 데모와 오류 사례를 공유합니다. “이번 주 결과 → 검증 근거 → 막힌 점 → 다음 담당·기한”을 기록하고, 두 명씩 서로의 데이터와 코드를 검토합니다. 회의자료 08·09를 역할과 일정 논의에 활용합니다.

06 / START HERE

첫 주에 바로 실행할 6가지

  1. 문제 한 문장 확정농지 점유 후보·불일치 원인·다음 확인행동 중 무엇을 시연할지 합의
  2. 시범지역과 자료목록 작성영상·필지·건물·행정·검증 자료의 출처, 시점, 좌표계, 담당, 확보상태 기록
  3. 경계와 라벨 기준 정의지붕/지상 외곽을 구분하고 창고·축사·컨테이너 등 대상 포함 기준을 문서화
  4. 설명할 대표 사례 선정실제 중첩, 위치 불일치, 시점 차이, 경계 의미 차이, 자료 미확보 사례를 구성
  5. 연구질문과 정답 기준 고정독립 검토자, 시험지역, 측정 지표, 미확정 처리, 목표값 결정 절차를 기록
  6. 역할·첫 산출물 배정4인 담당과 검수 파트너, 2주차 완료 기준, 자료 제공 협의사항을 정리
07 / DELIVERABLES

최종 발표에서 보여줄 것

01

재현 가능한 연구자료

자료목록·데이터 사전·라벨 지침·공간분할·전처리 코드·학습설정·모델 버전. 원본 제공 제한이 있으면 재현 절차와 접근조건을 기록합니다.

02

끝까지 작동하는 MVP

영상/분석결과 입력 → 건물 후보 → 필지 중첩 → 근거·미확인 정보 → 다음 행동 → 검토이력 → 결과표의 흐름을 시연합니다.

03

검증 보고서와 연구논문 초안

문제·선행연구·RQ/가설·자료·방법·실험·오류와 한계·후속과제. 실제 수치와 설명용 예시를 구분하고 개선되지 않은 결과도 기록합니다.

6개월·1년 후속 연구

14주 MVP 이후 6개월에는 독립 지역 검증과 공간불확실성 분석을 확장합니다. 1년에는 자료 이용·접근권한과 업무 실증 여건을 확보한 범위에서 다기관 검토, 시계열 변화, 예방적 확인서비스를 검토합니다. 기간은 제안 로드맵입니다.
